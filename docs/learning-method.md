# 数学・物理の理解と学習法

Word 版：[learning-method.docx](learning-method.docx)

## 1. 理解の二つの軸

数学や物理における「理解」には、性質の異なる二つの軸がある。

- **事象の理解**：幾何平面、自然現象、電子回路などの仕組みやふるまいを捉えること。
- **問題を解く力**：公式を使って値やベクトルの向きを求められること。

どちらか一方だけでは成り立たない。ただし両者は単に配分を考える対象ではなく、計算結果を現象に戻して解釈し、現象から式の形を予想するという往復によって互いに深まっていく。

## 2. 理解すべき事柄のリスト

### 2.1 事象の理解

| 項目 | できている状態の目安 |
|---|---|
| 用語・定義 | 問題文に出てくる用語を、自分の言葉で説明できる |
| 仕組み・ふるまい | 何がどう変化し、何が原因で何が結果かを説明できる |
| 表現の行き来 | 同じ内容を式・グラフ・図・言葉のあいだで相互に変換できる |
| 定性的な予測 | 計算する前に、結果がおおよそどうなるか（増えるか減るか、向きはどちらか）を予想できる |

### 2.2 問題を解く力

問題を解く過程は、次の段階に分けて捉えられる。

| 段階 | 内容 |
|---|---|
| ① モデル化 | 文章や現象を図・物理モデルに置き換える（どこに力がかかるか、何を質点とみなすか など）。応用問題で詰まる原因は公式選択よりもここにあることが多い |
| ② 公式の選択 | 与えられた値から最終的に求めたい値へ進む道のりがわかる |
| ③ 公式の記憶 | 文字、文字の意味、単位、係数と次数を書き起こせる |
| ④ 適用条件の把握 | その公式がいつ使え、いつ使えないかがわかる（等加速度運動に限る、理想気体が前提、小角度近似 など） |
| ⑤ 計算 | 具体的な値を代入して正しく計算できる |
| ⑥ 妥当性の確認 | 単位（次元）が合っているか、極端な値で常識的な結果になるか、符号や向きがおかしくないかを確かめられる |

### 2.3 分野を横断する事柄

- **公式同士のつながり**：少数の基本式から他の式を導ける。導出の流れがわかると暗記する量そのものが減る。
- **前提となる技能**：式変形、三角比、微分など、後の単元で道具として使う技能。ここに穴があると後で致命傷になる。
- **メタ認知**：「わかったつもり」と「自力で解ける」を区別し、自分の穴を把握できること。

## 3. 勉強法

### 3.1 基本方針

- **全体から細部へ**：最初からすべてを分かろうとせず、まず用語・定義など問題を解くことに直接関わる事柄から始め、どんどん先に進んで後から細部を詰める。全体像があると、細部に「何のための知識か」という意味が付き、結果的に理解が早くなる。
- **先送りしてよいものと、いけないもの**：用語の深い意味や発展的な話題は先送りしてよいが、道具となる技能（計算・式変形など）は先送りしない。数学は積み上げ型であり、前提の穴は後から効いてくる。
- **入口は速く、出口は深く**：入口は解法例を使って速く、出口は自力での再現と時間をかけた思考で深く。習熟度に応じて方法を切り替える。
- **忘却を前提にする**：一度覚えたことも放っておけば忘れる。復習の仕組みを最初から組み込む。

### 3.2 学習段階に応じた方法論

#### 段階1：導入（未修分野）

初学者がゼロから考えると負荷が大きすぎて何も残らないため、解法例から型を吸収するのが効率的である。

1. 例題の解き方を読み、公式と具体的な計算式を手で書き起こす。読むだけより書くほうが記憶に残る。
2. 例題を閉じ、白紙から自力で再現する。解答を読んで納得した感覚と、自力で再現できる能力は別物である。
3. 類題を解く。1分程度考えてわからなければ答えを見てよい。
4. 答えを見た問題には印を付け、翌日以降にもう一度解く。

#### 段階2：定着

型が身についてきたら、思い出す練習と、自分で手がかりを探す経験を増やす。

1. 考える時間を5分程度に延ばす。すぐ答えを見る習慣が続くと、見たことのある問題しか解けなくなる。
2. 公式は見て覚えるのではなく、白紙に書き出して確認する。
3. 解いた後に「何を手がかりに、どの公式を選んだか」を一言メモする。
4. 後回しにしていた細部（用語の意味、公式の導出、適用条件）を詰め始める。

#### 段階3：習熟・応用

この段階では解法例に頼ることがむしろ逆効果になる。詰まって考える時間そのものが力になる。

1. 考える時間を15分以上とり、答えを見る前に複数の方針を試す。
2. 単元をまたいで問題を混ぜて解く。同じ単元を続けて解くと、公式選択の訓練にならない。
3. 解いた後に必ず単位と極端な場合で検算する。
4. 計算結果を現象に戻し、何を意味するかを言葉で説明する。

### 3.3 目的別のメソッド

| 目的 | 方法 |
|---|---|
| 事象の理解 | ・計算前に結果を予想し、計算後に答え合わせする<br>・極端な場合（質量0、角度90°、時間無限大など）で式がどうふるまうか考える<br>・何も見ずに、他人に説明するつもりで書く。詰まった箇所が理解の穴<br>・図やグラフを自分で描く |
| 公式の暗記 | ・白紙に書き出す（思い出す練習のほうが定着する）<br>・単位から式を復元できるか確かめる（係数以外は単位で検算できる）<br>・暗記カードは「表：状況や条件／裏：式・各文字の意味・適用条件」にする<br>・翌日、3日後、1週間後と間隔を空けて復習する<br>・基本式と派生式を導出の流れでまとめた1枚の地図を作る |
| 問題演習 | ・例題を見る→閉じて再現→類題を自力で解く、の3段階を1セットにする<br>・考える時間は学習段階に応じて延ばす（1分→5分→15分以上）<br>・答えを見た問題は翌日以降に解き直す<br>・公式選択の手がかりをメモし、問題タイプを見分ける力を育てる<br>・単元を混ぜて解く<br>・最後に単位と極限で検算する |
