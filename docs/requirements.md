# study-planner 要件定義

週間の学習進捗を管理するアプリ。対象は自分1人。
学習計画は「学習計画 v4（英語・数学・物理・電験三種）」に準拠する（2026/10/24〜2027/3/21、週は土曜はじまり）。

## 1. 基本構成
- 形態：PWA（スマホ・PCのブラウザで動作、ホーム画面に追加可）
- 開発・公開：GitHub（rolly634/study-planner）、GitHub Pages で公開
- データ：Supabase（無料枠）に保存し、端末間で同期
- 認証：自分用の1アカウントのみ（メールアドレスとパスワード）
- テーブル：task_done（完了）、marks（○△×）、achieved（目標達成）、sessions（学習時間）、active_timer（計測中）、items（教材の項目）。すべて行レベルセキュリティで本人のみ

## 2. 日次画面
### 左：今日の学習課題
- 計画v4の「週ごとの範囲」と「時間配分」から自動生成
  - 平日：数学2h／物理1.5h／電験2h／復習0.5h
  - 土：数学4.5h／物理4h／英語2h／電験1h／復習0.5h
  - 日：数学3.5h／物理3h／英語2h／復習0.5h
  - 3/5〜3/20 は電験のみ
- 科目ごとの範囲（例：W1 数学＝三角関数 II・B 52–63／合格る 43–51）を表示

### 右：その日の実際の進捗
- 課題ごとの完了チェック
- 目標を達成した科目にチェック
- ○△×の記録（問題番号ごと）
  - ○ 自力で正解／△ 迷った・遅い／× 解けない
  - △×は自動で復習リストへ。2回目は△×だけを出題

### 先取り（今週の残りの課題）
- 各科目の課題の下に「先取り（残りn）」を折りたたみで表示し、今週の明日以降に割り当てられた教材の課題を順番どおりに並べる（教材以外の課題は対象外）
- 今日の課題と同じく完了チェックと○△×の記録ができる。予定日を曜日で表示する
- 先取りで終えた課題は翌日以降の予定から外し、残りを教材ごとに前へ詰める。各日の問題数は元の予定と同じにし、週の終わりを空ける
- 今日の一覧は変えない（今日先取りした分は翌日の画面から反映）。数日かけて進める章（電験）は、完了したら以降の日から外すだけ
- 過去の日に終わらなかった課題は「持ち越し」のまま表示し、詰め直しには含めない
- 過去の日を開いたときは、その日時点の割り当てを表示する

### TIPS
- その日の学習範囲に合わせたトピックを表示（例：三角関数の加法定理のコツ、力学の運動方程式の立て方）

## 3. タイマー
- 科目ごとに開始／停止し、学習時間を加算
- 開始時刻をDBに保存し、表示時は「現在時刻−開始時刻」で計算する
  - バックグラウンド、アプリ終了→再起動後、別端末でも正しい経過時間が分かる
- 停止時に学習セッション（科目・開始・終了・時間）として記録

## 4. 予定と実績の可視化
- 週ビュー：科目ごとの計画時間とタイマー実績の棒グラフ（基準は週51h）
- 日ビュー：今日の科目別の予定と実績を進捗バーで表示
- 差分：科目ごとの過不足（+1.5h／−2h など）を数値表示、遅れている科目を色で強調
- 課題の消化率：その週の範囲のうち完了した割合
- 累計：10/24からの総学習時間と、計画に対する累計の差（遅れ・貯金）

## 5. Claude連携
- Claudeアプリで音声またはテキストで進捗を報告
- Claude が Supabase コネクタ経由でDBに直接記録
  - 例：「数学52〜58終わった、55と57が×」→ 課題完了と○△×が反映

## 6. 誤答アプリとの連携（study-mistakes-app）
仕様の詳細はプロジェクト文書「アプリ連携の仕様」、テーブルは `supabase/mistakes.sql`。
- 写真待ち：×をつけたのに誤答が未登録の項目を「📷 写真待ち」として今日の画面と復習タブに表示。「確認した」「まとめて確認」で消える。誤答を登録すると自動で消える。毎日19時に Claude が通知
- 誤答の状況：教材の項目に「誤 定着数/問題数」と「要注意」（誤答アプリで2回続けて解けなかった）を表示。○△×ダイアログにも表示
- 定着の○：項目につながる誤答が全部定着すると、marks に ○ が自動で入る（source = mistakes、履歴に「誤答アプリで定着」と注記）
- 復習時間：誤答アプリが sessions（subject = review, source = mistakes）に自動で記録。このアプリの復習タイマー・手動追加はなくした。1日30分で復習の目標達成が自動で付く

## 7. 今回は対象外（後で検討）
- 入試・電験までのカウントダウン
- 申込・出願の通知（電験申込 11/9〜11/26、理科大出願 1/7〜2/24）
- 遅れたときの調整案の提案
