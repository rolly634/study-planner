# 学習プランナー（study-planner）

週間の学習進捗を管理する PWA。学習計画 v4（数学・物理・英語・電験三種、2026/10/24〜2027/3/21）に沿って、
その日の課題を自動で並べ、実際の進捗・学習時間・○△×を記録する。

## できること
- **今日**：左に今日の学習課題（教材の問題・節ごと）、右に実際の進捗（学習時間、完了数、○△×、目標達成チェック）。終わらなかった課題は翌日以降に「持ち越し」で表示
- **タイマー**：科目ごとに開始／停止。開始時刻を保存して経過時間を計算するので、バックグラウンドやアプリを閉じたあとも正しく続く。手動で時間を追加することもできる
- **TIPS**：その日の範囲（三角関数、力学、直流回路など）に合わせたポイントを表示
- **予実**：週ごとの科目別 計画 vs 実績、日ごとのグラフ、課題の消化率、開始日からの累計（貯金／遅れ）
- **復習**：最後の結果が△・×の問題の一覧。○になると外れる。誤答アプリで要注意の項目も表示
- **誤答アプリ連携**：×をつけた問題の「📷 写真待ち」、項目ごとの誤答の定着状況、誤答アプリが記録した復習時間（[docs/requirements.md](docs/requirements.md) の 6）

## 構成
ビルド不要の静的サイト（HTML / CSS / JavaScript モジュール）。GitHub Pages でそのまま公開できる。

| ファイル | 内容 |
|---|---|
| `js/catalog.js` | 教材データ（教材目次集 v4 の章・問題・計画週） |
| `js/plan.js` | 期間、時間配分、日ごとの課題の割り振り |
| `js/tips.js` | 章ごとの TIPS |
| `js/store.js` | データ保存と Supabase 同期（端末内に保存し、ログイン中は変更を送ってサーバーの内容を取り込む） |
| `js/config.js` | Supabase の URL と公開用キー |
| `supabase/` | テーブル定義と教材データ（items）の SQL。`mistakes.sql` は誤答アプリとの連携 |
| `js/app.js` | 画面 |
| `sw.js` | オフライン用キャッシュ（更新時は `VERSION` を上げる） |

## テスト
```sh
python3 tests/test_mistakes_link.py   # 誤答アプリ連携の表示（Playwright）
```

## ローカルで動かす
```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 同期と Claude 連携
- 設定タブでログインすると Supabase と同期する（スマホ・PC で同じ記録）。未ログインやオフラインでも端末内で使える
- Claude アプリで話した進捗は、Supabase コネクタ経由で Claude がデータベースに書き込み、アプリにすぐ反映される。書き込み方は [docs/claude-reporting.md](docs/claude-reporting.md)

要件は [docs/requirements.md](docs/requirements.md)。
